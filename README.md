# КПО «Восток»: предложение и обращение

Статический сайт для публикации общественного предложения о межведомственной проверке КПО «Восток» и запуске проверяемого плана мер.

- `index.html` — главная страница: цель, документы, порядок действий и исходный обзор.
- `docs/proposal.md` — аналитическая записка, реестр источников и ограничений доказательств, план и матрица контроля.
- `docs/appeal.md` — проект обращения в Администрацию Президента РФ и памятка заявителю.
- `docs/proposal.html`, `docs/appeal.html` — печатные версии.
- `docs/presentation.html` — краткая презентация, один слайд на печатную страницу.

## Просмотр и публикация

Для сайта не нужны серверная логика, учётные данные или сборка: HTML-файлы уже включены в репозиторий. Можно открыть `index.html` в браузере или запустить:

```sh
python3 -m http.server 8000
```

Затем открыть http://localhost:8000/. Для GitHub Pages публиковать корень выбранной ветки. Сайт сам не подаёт обращения и не собирает персональные данные.

Для PDF откройте нужный документ и выберите «Печать → Сохранить как PDF». В обращении сначала заполните реквизиты и удалите служебную памятку из направляемой копии. Никогда не коммитьте заполненную копию с персональными данными.

## Обновление документов

Редактируйте исходники Markdown, затем пересоберите HTML:

```sh
python3 -m pip install Markdown==3.7
python3 tools/build_docs.py
python3 tools/build_docs.py --check
```

Презентация и главная страница редактируются отдельно. Проверяйте согласованность просьб, дат и ссылок между материалами. В Codespaces сохраняйте сгенерированные HTML через `commit_from_codespace`, если среда не имеет права `git push`.

## Статус материалов

Это общественное предложение и шаблон для подачи, не экспертное заключение и не гарантия принятия мер. Реестр записки отделяет сведения исходного обзора от того, что ещё нужно запросить. Повторная независимая проверка внешних судебных актов, измерений и актуальных правил приёмной не заявляется. Перед направлением проверьте первоисточники, действующие нормы, реальные приложения и реквизиты.

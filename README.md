# После сортировки остаётся полигон

Материалы общественного проекта о системном дефекте регулирования объектов обращения с твёрдыми коммунальными отходами — на примере КПО «Восток» (д. Поцелуево, городской округ Егорьевск, Московская область).

**Тезис проекта:** объект может одновременно сохранять весь комплект действующих разрешений и быть предметом многочисленных зафиксированных превышений гигиенических нормативов в жилой застройке. Это не сбой правоприменения, а пробел в правилах: данные фактических измерений не влекут автоматического пересмотра расчётной модели, на которой построен допуск объекта.

**Чего проект добивается:** не закрытия объекта, а межведомственного поручения — изменить условия работы и правила допуска.

## Состав материалов

| Файл | Что это | Для кого |
|---|---|---|
| `index.html` | Публичная страница проекта. На первом экране (раздел «Что предлагается») — цель, ссылки на документы, шесть просьб и порядок действий. Ниже — исходный аналитический обзор кейса со ссылками на источники. | широкая аудитория, СМИ |
| `docs/proposal.md` | Аналитическая записка: постановка проблемы, нормативная рамка, фактическая база с указанием статуса каждого сведения, дерево причин, распределение компетенций, предложения по трём горизонтам, запросы, критерии оценки ответа и матрица контроля, реестр источников. | приложение к обращению, органы власти |
| `docs/appeal.md` | Проект обращения в Администрацию Президента Российской Федерации: полная версия с шестью раздельными просьбами, краткая версия для электронной формы, памятка по подаче, срокам и обжалованию формального ответа. | заявитель |
| `docs/presentation.html` | Презентация на 8 слайдов по материалам записки, с печатным оформлением. | публичные выступления, встречи с депутатами |

## Как опубликовать страницу

Репозиторий рассчитан на GitHub Pages:

1. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
2. Через несколько минут страница доступна по адресу `https://<аккаунт>.github.io/<репозиторий>/`.
3. Презентация — по адресу `.../docs/presentation.html`.

Локальный просмотр без установки зависимостей:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000/ и http://localhost:8000/docs/presentation.html
```

## Как сохранить материалы в PDF

- **Презентация:** открыть `docs/presentation.html` → печать браузера (Ctrl/Cmd+P) → «Сохранить как PDF», ориентация «Альбомная», включить печать фоновой графики. Каждый слайд печатается на отдельной странице.
- **Публичная страница:** `index.html` → печать → «Сохранить как PDF», ориентация «Книжная». Навигация при печати скрывается.
- **Записка и обращение:** это Markdown. Для PDF можно использовать любой конвертер, например `pandoc docs/proposal.md -o proposal.pdf`, либо просто открыть файл на GitHub и распечатать страницу.

## Порядок действий перед подачей обращения

1. В `docs/appeal.md` заполнить поля в квадратных скобках (ФИО, адрес для ответа, телефон, дата, объём приложений).
2. Сверить реквизиты судебных дел и даты по официальным карточкам на сайтах судов — материалы датированы моментом подготовки и могут устареть.
3. Приложить только те документы, которые фактически есть на руках. Сведения из вторичных источников не заявлять как установленные факты.
4. Удалить из отправляемого текста служебные пояснения (выделены цитатным блоком), разделы «Краткая версия» и «Памятка по подаче».
5. Подать обращение через <http://letters.kremlin.ru/> и продублировать почтой с уведомлением о вручении.
6. Ответы фиксировать в матрице контроля (раздел 8 записки), формальные отписки обжаловать.

- Материалы подготовлены по открытым источникам: нормативным актам, официальной статистике, опубликованным судебным актам, публикациям СМИ и общественных организаций.
- Ни одно утверждение не является самостоятельно установленным фактом нарушения и не подменяет результаты государственного экологического контроля.
- Первичные протоколы инструментальных замеров, паспорт контрольного мероприятия в ФГИС ЕРКНМ и геодезические материалы о фактической высоте карт независимо не извлекались; эти пробелы прямо перечислены в разделе 7 записки и оформлены как запросы, а не как выводы.
- Сайт проекта статический и не собирает персональные данные.
